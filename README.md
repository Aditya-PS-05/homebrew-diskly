# Homebrew tap for Diskly

[Diskly](https://diskly.net) is a disk usage analyzer for macOS. It shows where your storage went and what is safe to remove.

## Install

```sh
brew install --cask aditya-ps-05/diskly/diskly
```

Requires macOS 14 or later on Apple silicon. Diskly updates itself once installed.

## Uninstall

```sh
brew uninstall --cask diskly
```

Add `--zap` to also remove Diskly's settings and remembered scans.
